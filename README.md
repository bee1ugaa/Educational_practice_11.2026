# Практическая работа №1

Тема: «Сравнение архитектуры операционных систем Windows NT, Linux и MINIX 3».

Отчёт оформлен по «Правилам оформления отчётной документации для студентов»
(поля 3/1,5/2/2 см; Times New Roman 14 пт, заголовки 16 пт полужирные,
подписи таблиц 12 пт; интервал 1,5; красная строка 1,25 см; нумерация страниц внизу
по центру со второй страницы; «Продолжение/Конец Таблицы N» для многостраничных таблиц).

## Файлы

- `report/Практическая_работа_1.docx` – отчёт (Word);
- `report/Практическая_работа_1.pdf` – тот же отчёт в PDF;
- `src/build.js` – генератор DOCX (текст отчёта, таблицы, оглавление);
- `src/make.py` – сборка с подбором номеров страниц оглавления и разбиения таблиц.

## Пересборка

```bash
python3 src/make.py
```

Перед сдачей заполнить на титульном листе поля «Дисциплина», «Выполнил»,
«Группа» и дату выполнения.
